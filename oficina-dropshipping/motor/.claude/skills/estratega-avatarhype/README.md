# estratega-avatarhype

Esta carpeta está reservada para tu skill **estratega-avatarhype** de claude.ai.

Copia aquí el archivo `SKILL.md` de la skill (y cualquier archivo que la acompañe). Mientras no exista
`SKILL.md`, Claude Code ignora esta carpeta y los agentes trabajan sin ella.

Cómo obtener el texto: en claude.ai, abre la skill desde Configuración → Skills y copia su contenido, o pídele a Claude
en un chat que te muestre el SKILL.md completo de la skill para pegarlo aquí.
